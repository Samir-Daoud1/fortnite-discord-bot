# LarsBotMain

A Discord bot for checking and managing Fortnite accounts — locker, item shop, STW inventory, friend management, and more.

## ✨ Features

### Account
- **Account Info** — pull up general account details
- **Account Level** — check your Fortnite level
- **Profile** — view profile stats

### Friends
- **Add Friend** — send a friend request from the bot
- **Remove Friend** — remove a friend

### Cosmetics & Shop
- **Locker** — view your owned cosmetics
- **Equip** — equip a specific item
- **Item Shop** — see today's featured shop

### Save the World
- **STW Inventory** — llamas, resources, schematics
- **STW Profile** — STW stats
